# ONSSA — Portail e-services

- Autorité source : Office National de Sécurité Sanitaire des Produits Alimentaires (ONSSA)
- URL source : https://eservice.onssa.gov.ma/Default.aspx
- Collecté le : 2026-11-23
- Catégorie : e-services
- Langue : fr

## Extrait public sélectionné

Le portail de services en ligne référence l’homologation des produits
phytopharmaceutiques, l’Index phytosanitaire, les sociétés phytosanitaires et
organismes agréés, les inspecteurs agréés BPE, les limites maximales de
résidus, les modifications/retraits d’homologations et d’agréments, les
procédures, notes de service et textes juridiques.

Le portail rappelle que les utilisateurs doivent vérifier l’exactitude et
l’actualité des données auprès de l’ONSSA.
